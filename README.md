# Hospital Active Directory Lab 
## What I Did 
- Built an Active Directory in Windows Server for a Hospital
- Create an organization unit (OU) for the staff
- Create Security Group for Hosp Staff Group
- Create user account, add user to then group and then verify user appears in Active Directory Users and Computers.
